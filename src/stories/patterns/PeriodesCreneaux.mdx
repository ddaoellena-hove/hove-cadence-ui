# Pattern — Périodes continues et créneaux récurrents

**Quand l'utiliser** — saisir plusieurs périodes datées, ou des créneaux répétés par jour. **Ne pas confondre avec** — Planification / temps, qui visualise des amplitudes de service.

## Anatomie
```
SegmentedControl : Périodes | Créneaux
RepeatableFieldGroup
  Période : FieldRow(DatePicker withTime × 2)
  Créneau : FormField(Checkbox × 7) · FieldRow(TimePicker × 2)
DescriptionList (récapitulatif)
FormActions
```

## Variantes
Périodes continues ; créneaux récurrents, nuit comprise.

## États
Erreur par bloc (`getError`) ; saisie non confirmée (`onInputStateChange`).

## Comportements
Changer de mode conserve les deux saisies ; seul le mode actif est appliqué. Une fin plus tôt que le début désigne le lendemain ; des heures égales sont refusées.

## Responsive
`FieldRow` passe en une colonne à 1024px ; les jours passent à la ligne.

## Accessibilité
Chaque jour est une `Checkbox` à libellé cliquable, groupée par `FormField`.

## Règles
- ✅ Logique hors du rendu : `schedule-rules.ts`, testée.
- ✅ Fuseau et changements d'heure décidés par le produit.
- ❌ Ne pas copier ces règles dans le noyau : elles dépendent du métier.
