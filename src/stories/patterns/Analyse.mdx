# Pattern — Tableau de bord d'analyse

**Quand l'utiliser** — explorer des données sur une période : indicateurs, évolution, répartition, classement. **Ne pas confondre avec** — Supervision (temps réel), Liste / index.

## Anatomie
```
PageHeader (h1 + période)
CardGrid (indicateurs)
LineChart (évolution)
CardGrid min=360 fit (Heatmap + BarList)
```

## Variantes
Jeu de graphiques variable selon le domaine.

## États
Chargement / erreur **par bloc** : chaque graphique reçoit `state` (et `onRetry`) à partir de la requête.

## Comportements
Une seule période pilote tous les blocs ; un clic sur une cellule / barre ouvre la liste filtrée.

## Responsive
Grilles fluides (`auto-fill` / `auto-fit`) ; les graphiques suivent leur conteneur.

## Accessibilité
Un seul `h1`, graphiques en `h2` avec `title` ; alternative « Voir les données ».

## Règles
- ✅ Jamais de largeur fixe en px : grilles fluides.
- ✅ Graphiques encadrés (`framed`, surface de `Card`) : ils restent délimités côte à côte.
- ❌ Pas de graphique sans `title` ni état.
