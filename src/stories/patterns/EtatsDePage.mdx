# Pattern — États de page

**Quand l'utiliser** — le vocabulaire des états pleine page, réutilisé par tous les patterns. **Ne pas confondre avec** — un état *inline* (dans un `DataTable`, une `Card`, un graphique : `EmptyState size="inline"`).

## Anatomie
```
Chargement  → PageHeader + Skeleton (squelettes de contenu)
Erreur      → EmptyState variant="error" (+ Réessayer)
Accès refusé→ EmptyState variant="error"
Introuvable → EmptyState variant="error" (+ Retour à l'accueil)
Vide        → EmptyState variant="empty" (+ action de création)
```

## Variantes
`size="page"` (vue entière) ou `size="inline"` (dans un composant).

## États
C'est le pattern des états lui-même.

## Comportements
L'erreur et le « sans résultat » portent `role="status"` ; chaque état propose l'action de sortie adaptée (réessayer, créer, revenir).

## Responsive
`EmptyState size="page"` reste centré ; padding 48px.

## Accessibilité
`main` nommé (coque) ; message annoncé (`role="status"` pour erreur / sans résultat).

## Règles
- ✅ Toujours une action de sortie (réessayer, créer, revenir).
- ❌ Pas d'état vide bricolé à la main : `EmptyState`.
