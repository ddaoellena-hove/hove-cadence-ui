# Pattern — Sélection transactionnelle multiple

**Quand l'utiliser** — choisir plusieurs objets dans un catalogue, puis confirmer en une fois. **Ne pas confondre avec** — un `Autocomplete multiple` seul, sans étape de confirmation.

## Anatomie
```
PageSection : liste confirmée + GhostButton
Drawer
  Autocomplete multiple
  TableCard (sélection temporaire, retrait)
  Pied : Annuler · Confirmer (n)
```

## Variantes
Recherche côté serveur : `onInputChange`, `filter={false}`, `loading`.

## États
Vide (`EmptyState`), chargement (`loading`), aucun résultat (`noResultsLabel`), erreur (`InlineAlert`).

## Comportements
La copie de travail ne rejoint la donnée qu'à la confirmation ; annuler la jette. Le produit fournit l'identité de déduplication.

## Responsive
Le `Drawer` occupe toute la largeur sur mobile.

## Accessibilité
L'aide parle d'objets, jamais de « drawer » ; le nombre sélectionné figure dans l'action.

## Règles
- ✅ Annuler ne modifie pas la donnée initiale.
- ❌ Ne pas créer de `MultiSelect` : `Autocomplete multiple` existe.
