# Pattern — Paramètres

**Quand l'utiliser** — réglages d'un espace : sections, bascules, choix exclusifs. **Ne pas confondre avec** — Formulaire (créer/éditer un objet).

## Anatomie
```
PageHeader (h1)
PageSection(s) : rangées titre + description + contrôle (Toggle / RadioButton)
FormActions (Enregistrer)
```

## Variantes
**Décision** : enregistrement **explicite** par défaut (bouton « Enregistrer ») ; un réglage à **effet immédiat** (`Toggle`) l'annonce dans sa section.

## États
Pas d'état vide ; erreur d'enregistrement remontée par un toast ou `InlineAlert`.

## Comportements
Un `Toggle` à effet immédiat applique le changement sur-le-champ ; les réglages groupés attendent « Enregistrer ».

## Responsive
Une colonne ; le contrôle reste à droite de son libellé.

## Accessibilité
Un seul `h1`, sections en `h2` ; chaque contrôle porte un `aria-label` (ou un libellé associé) ; `Toggle`/`RadioButton` pilotés par `state`.

## Règles
- ✅ Indiquer clairement ce qui est immédiat et ce qui demande « Enregistrer ».
- ❌ Pas de prop `checked` : piloter par `state`.
