# Pattern — Assistant / import

**Quand l'utiliser** — un parcours en étapes : import de fichier, vérification, transfert, reprise après erreur. **Ne pas confondre avec** — Formulaire (une seule page), Liste / index.

## Anatomie
```
PageHeader (h1)
Stepper (Fichier · Vérification · Import)
contenu de l'étape : FileUpload / ErrorSummary / ProgressBar
FormActions justify="between" (Précédent / Suivant)
```

## Variantes
Nombre d'étapes variable ; `ColorField` pour corriger des couleurs importées (GTFS).

## États
Chargement (transfert, `ProgressBar`), Erreur (reprise : `InlineAlert`/`ErrorSummary`), étape terminée revisitable.

## Comportements
Une étape terminée peut être revisitée ; l'erreur bloque le passage à l'étape suivante jusqu'à correction.

## Responsive
`Stepper` passe en vertical sous 1024 px.

## Accessibilité
Un seul `h1` ; `Stepper` annonce l'étape courante ; erreurs regroupées (`ErrorSummary`).

## Règles
- ✅ Validation avant chaque passage d'étape.
- ❌ Pas de perte des étapes déjà remplies en revenant en arrière.
