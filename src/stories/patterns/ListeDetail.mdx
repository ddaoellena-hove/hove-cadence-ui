# Pattern — Liste + détail latéral

**Quand l'utiliser** — consulter le détail d'un élément sans quitter la liste (`Drawer`). **Ne pas confondre avec** — Page de détail (page entière, URL propre), Liste / index (sans détail latéral).

## Anatomie
```
PageHeader (h1)
DataTable (onRowClick)
Drawer (détail) : InlineAlert · Accordion(DescriptionList, ActivityFeed)
```

## Variantes
Détail en `Drawer` (léger) ou navigation vers une Page de détail (contenu long).

## États
Liste : chargement / vide / erreur (voir Liste / index). Drawer : chargement du détail.

## Comportements
Clic (ou Entrée) sur une ligne ouvre le `Drawer` ; Échap le referme et rend le focus à la ligne.

## Responsive
Le `Drawer` couvre la largeur sur mobile.

## Accessibilité
`Drawer` = `dialog` nommé, focus piégé ; retour du focus à la ligne d'origine.

## Règles
- ✅ Un seul détail ouvert à la fois ; la liste reste visible derrière.
- ❌ Pas de détail long dans un `Drawer` : passer à une Page de détail.
