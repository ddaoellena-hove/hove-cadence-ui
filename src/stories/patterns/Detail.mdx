# Pattern — Page de détail

**Quand l'utiliser** — la page d'un seul objet : en-tête avec actions (dont une action destructive), onglets, sections, historique. **Ne pas confondre avec** — Liste + détail latéral (`Drawer`), Formulaire (édition).

## Anatomie
```
PageHeader (h1 + fil d'Ariane + actions : Modifier · Supprimer)
TabList (Informations · Historique)
PageSection(s) : DescriptionList / ActivityFeed
Modal (confirmation de l'action destructive)
```

## Variantes
Avec ou sans onglets ; action destructive présente ou non.

## États
Chargement (squelettes), erreur de chargement, accès refusé (voir États de page).

## Comportements
L'action destructive passe par une `Modal` de confirmation. Les onglets naviguent dans la page (pas d'URL obligatoire).

## Responsive
Les actions passent sous le titre si la place manque.

## Accessibilité
Un seul `h1`, sections en `h2` ; onglets au motif `tab`/`tabpanel` ; `Modal` nommée, focus piégé.

## Règles
- ✅ Une seule action destructive, confirmée.
- ❌ Pas de second `h1`.
