# Pattern — Coque d'application

**Quand l'utiliser** — toute page de l'app. C'est la coque qui porte la navigation et le contenu. **Ne pas confondre avec** — un pattern de contenu (Liste, Formulaire…), qui vit *dans* la coque.

## Anatomie

```
AppLayout (main nommé)
├─ Sidebar (nav nommée) : sections · périmètre (scope) · utilisateur
└─ contenu
   ├─ PageHeader (h1 + fil d'Ariane + actions)
   ├─ {children} : le pattern de contenu
   └─ Toaster (monté une seule fois)
```

## Variantes
Sidebar repliable ; avec ou sans fil d'Ariane / sélecteur de périmètre.

## États
Les états vivent dans le contenu — voir **Pattern — États de page**.

## Comportements
`useToast()` partout, un seul `<Toaster />`. La Sidebar porte le périmètre (`scope`) et l'utilisateur en pied.

## Responsive
Sidebar repliable sous 1024 px ; le contenu s'élargit sans code applicatif.

## Accessibilité
Repères `main` et `nav` nommés (fournis par `AppLayout` / `Sidebar`), un seul `h1` (`PageHeader`).

## Règles
- ✅ Le contenu commence par un `PageHeader` ; pas de padding à rajouter.
- ❌ Pas de `Header` ni de wrapper `position: fixed`.
