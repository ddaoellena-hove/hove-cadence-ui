<div className="g h2">Layout recommandé</div>

```tsx
// ✅ Structure de page standard
<AppLayout
  sidebar={
    <Sidebar
      product="datahub"
      clientName="Bordeaux Métropole"
      sections={[…]}
      scope={{ options: reseaux, value: reseau, onChange: setReseau }}
      user={{ name: "Hector Malot", email: "hector.malot@hove.com" }}
    />
  }
>
  {/* Localisation et titre de page */}
  <PageHeader
    breadcrumbs={
      <Breadcrumbs items={[
        { id: "home", label: "Accueil", href: "#" },
        { id: "section", label: "Perturbations", href: "#" },
        { id: "current", label: "Vue détaillée" },
      ]} />
    }
    title="Perturbations non planifiées"
  />

  {/* Navigation intra-page */}
  <TabList aria-label="Vue">
    <Tab label="En cours" variant="active" onClick={…} />
    <Tab label="Historique" onClick={…} />
    <Tab label="Statistiques" onClick={…} />
  </TabList>

  {/* Contenu */}
</AppLayout>
```

<div className="g h2">Règles</div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Toute page vit dans <code>AppLayout</code> : la <code>Sidebar</code> se fond dans le fond de l'app et le contenu est dans un conteneur arrondi qui suit sa largeur (dépliée ou repliée).</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Périmètre et profil utilisateur vont en pied de <code>Sidebar</code> (<code>scope</code>, <code>user</code>) : il n'y a plus de <code>Header</code>.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne jamais décaler ou centrer la <code>Sidebar</code> — elle est toujours ancrée au bord gauche de la fenêtre.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne jamais tronquer la hauteur de la <code>Sidebar</code> — elle doit aller du haut au bas de l'écran.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Toujours afficher un <code>Breadcrumbs</code> dès que l'utilisateur est à plus d'un niveau de profondeur.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Le dernier item du <code>Breadcrumbs</code> est la page courante — sans <code>href</code>, souligné.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Utiliser <code>Dropdown</code> <code>variant="button"</code> dans le breadcrumb pour les sélecteurs de produit/module.</span></div>

## Parcours à plusieurs niveaux

Utiliser **SegmentedControl** (apparence de l’ancien Alt) pour choisir la vue principale, puis **SecondaryTab** dans un **TabList level="secondary"** pour ses sous-vues. Le SegmentedControl reste un groupe autonome, sans TabList autour. Il épouse ses segments, aligné à gauche, et ne s’étire jamais sur toute la largeur de la page. Voir la story Composants/Navigation/SecondaryTab « Deux niveaux (SegmentedControl + SecondaryTab) ».
