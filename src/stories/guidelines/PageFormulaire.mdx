# Page de type Formulaire

Référence : **CreateScenarioForm** — alignée sur `GUIDELINES.md` (§ Layout & spacing, recette 3).

<div className="g h2">1. Structure globale</div>

La page formulaire se lit en **largeur pleine et lecture descendante**. Les panneaux de premier niveau (formulaire, puis synthèse / vérification) s'**empilent verticalement** dans un conteneur limité à `max-width: 720px`. Le multi-colonnes n'est autorisé qu'**à l'intérieur** d'une section (champs courts et liés).

```
┌──────────────────────────────────────────┐
│  Header de page (identique au dashboard) │
├──────────────────────────────────────────┤
│  Panneau 1 — Formulaire (sections)       │
│  max-width 720px                         │
├──────────────────────────────────────────┤
│  Panneau 2 — Synthèse / vérification     │
├──────────────────────────────────────────┤
│                     Actions (à droite)   │
└──────────────────────────────────────────┘
```

```tsx
// Conteneur de page : flexDirection "column" → les panneaux s'empilent
<div style={{ display: "flex", flexDirection: "column", gap: 32, maxWidth: 720 }}>
  <PageHeader />
  <FormPanel />      {/* sections empilées, gap 32 */}
  <SummaryPanel />   {/* toujours EN DESSOUS du formulaire */}
  <FormActions />
</div>
```

<div className="spec">
  <div className="label">⚠️ Point ouvert — colonne cartographique</div>
  L'ancienne version de cette page décrivait un panneau formulaire de <code>560px</code> à gauche et une <b>carte contextuelle pleine hauteur à droite</b>.
  Cette disposition contredit la règle d'empilement de <code>GUIDELINES.md</code> et a été retirée.
  Si la carte à côté du formulaire est un vrai besoin produit (saisie géographique), il faut le trancher et l'inscrire dans <code>GUIDELINES.md</code> comme exception documentée.
</div>

<div className="g h2">2. Header de page</div>

Identique à la page dashboard : breadcrumb + titre en `--cadence-font-display`. Pas de `SegmentedControl` côté droit sur les pages formulaire.

<div className="spec">
  Même structure que le dashboard<br/>
  Padding de la zone de contenu : <code>24px 32px</code><br/>
  Pas d'actions à droite du header — les actions sont en bas du formulaire
</div>

```tsx
<h1 style={{ fontFamily: "var(--cadence-font-display)", fontSize: 28, fontWeight: 500,
             color: "var(--cadence-color-primary)", margin: 0 }}>
  Créer un scénario
</h1>
```

<div className="g h2">3. Sections du formulaire</div>

<div className="spec">
  <div className="label">Titre de section</div>
  Police : <code>--cadence-font-sans</code>, <code>16px</code>, weight 600, couleur <code>--cadence-color-primary</code> — casse normale<br/>

  <br/>
  <div className="label">Espacements</div>
  Gap entre champs : <code>20px</code><br/>
  Gap entre champs côte à côte (même ligne) : <code>12px</code><br/>
  Gap entre sections : <code>32px</code>

  <br/><br/>
  <div className="label">Champs</div>
  Composants : <code>TextInput</code>, <code>Dropdown</code>, <code>SegmentedControlAlt</code>, <code>DatePicker</code>, <code>CounterInput</code>, <code>TextArea</code> — toujours avec <code>label</code>
</div>

```tsx
<section style={{ display: "flex", flexDirection: "column", gap: 20 }}>
  <h2 style={{ fontFamily: "var(--cadence-font-sans)", fontSize: 16, fontWeight: 600,
               color: "var(--cadence-color-primary)", margin: 0 }}>
    Informations générales
  </h2>
  <TextInput label="Nom du scénario" placeholder="Ex : Perturbation ligne A" />
  {/* ✅ multi-colonnes autorisé à l'intérieur d'une section */}
  <div style={{ display: "flex", gap: 12 }}>
    <div style={{ flex: 1 }}>
      <Dropdown label="Réseau" options={reseaux} value={reseau} onChange={setReseau} />
    </div>
    <div style={{ flex: 1 }}>
      <Dropdown label="Cause" options={causes} value={cause} onChange={setCause} />
    </div>
  </div>
  <SegmentedControlAlt
    aria-label="Type"
    options={[{ value: "planned", label: "Planifié" }, { value: "unplanned", label: "Non planifié" }]}
    value={type}
    onChange={setType}
  />
</section>
```

<div className="g h2">4. Panneau de synthèse</div>

La synthèse (récapitulatif, vérification, prévisualisation) vient **sous** le formulaire, une fois la saisie posée — jamais en colonne à droite.

```tsx
<div style={{ display: "flex", flexDirection: "column", gap: 12 }}>
  <h2 style={{ fontFamily: "var(--cadence-font-sans)", fontSize: 16, fontWeight: 600,
               color: "var(--cadence-color-primary)", margin: 0 }}>
    Récapitulatif
  </h2>
  <TableCard
    title="Scénario à créer"
    columns={[
      { key: "type", content: <span>{type} · {cause}</span>, flex: 1 },
      { key: "periode", content: <span>{start} → {end}</span>, width: 220 },
    ]}
  />
</div>
```

<div className="g h2">5. Actions de soumission</div>

<div className="spec">
  Position : en bas du formulaire, alignées à droite<br/>
  Boutons : <code>PrimaryButton size="large"</code> — <code>outline</code> à gauche, rempli à droite<br/>
  3e action éventuelle : <code>Link hideArrow</code>, à gauche du groupe
</div>

```tsx
<div style={{ display: "flex", alignItems: "center", gap: 12, justifyContent: "flex-end" }}>
  {/* 3e action optionnelle */}
  <Link variant="secondary" hideArrow onClick={onSaveDraft}>
    Enregistrer comme brouillon
  </Link>
  <PrimaryButton size="large" outline label="Réinitialiser" onClick={onReset} />
  <PrimaryButton size="large" label="Créer le scénario" onClick={onSubmit} />
</div>
```
