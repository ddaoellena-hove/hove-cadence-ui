# Page de type Formulaire

Référence : **CreateScenarioForm**

<div className="g h2">1. Structure globale</div>

La page formulaire est un layout en **deux colonnes sans gap**, pleine hauteur, qui ne scroll pas au niveau de la page — chaque colonne gère son propre scroll.

```
┌──────────────────────────────────────────────────────────┐
│  Header de page (identique au dashboard)                 │
├────────────────────────┬─────────────────────────────────┤
│  Panel formulaire      │  Carte contextuelle (carte,     │
│  560px — scrollable    │  prévisualisation…)             │
│                        │  pleine hauteur — fixe          │
└────────────────────────┴─────────────────────────────────┘
```

```tsx
<div style={{ display: "flex", flexDirection: "column", height: "100vh", overflow: "hidden" }}>
  <PageHeader />
  <div style={{ display: "flex", flex: 1, overflow: "hidden" }}>
    <FormPanel />   {/* 560px, overflow-y: auto */}
    <MapPanel />    {/* flex: 1, border-left */}
  </div>
</div>
```

<div className="g h2">2. Header de page</div>

Identique à la page dashboard : breadcrumb + titre Uxum Grotesque. Pas de `SegmentedControl` côté droit sur les pages formulaire.

<div className="spec">
  Même structure que le dashboard<br/>
  Padding : <code>24px 32px</code><br/>
  Pas d'actions à droite du header — les actions sont dans le panel formulaire
</div>

<div className="g h2">3. Panel formulaire (colonne gauche)</div>

<div className="spec">
  <div className="label">Dimensions</div>
  Largeur fixe : <code>560px</code>, flex-shrink : <code>0</code><br/>
  Hauteur : <code>100%</code>, overflow-y : <code>auto</code><br/>

  <br/>
  <div className="label">Ombre</div>
  <code>box-shadow: 0 0 12px 0 rgba(0, 0, 0, 0.10), 0 0 2px 0 rgba(0, 0, 0, 0.25)</code><br/>
  Positionnée à droite du panel — le panel « flotte » au-dessus de la carte

  <br/><br/>
  <div className="label">Background</div>
  <code>#ffffff</code> — pas de border-radius (bords franc haut/bas)
</div>

```css
.form-panel {
  width: 560px;
  flex-shrink: 0;
  height: 100%;
  overflow-y: auto;
  background: #ffffff;
  box-shadow: 0 0 12px 0 rgba(0, 0, 0, 0.10),
              0 0 2px 0 rgba(0, 0, 0, 0.25);
}
```

Chaque section est séparée de la suivante par un `border-bottom`.

<div className="spec">

<div className="g h2">6. Actions de navigation (pied de panel)</div>

Le pied du panel est fixe (ne scroll pas) et contient les actions de navigation entre étapes.

<div className="spec">
  Position : collé au bas du panel, <code>position: sticky; bottom: 0</code><br/>
  Background : <code>#ffffff</code> avec <code>border-top: 1px solid #f0f0f0</code><br/>
  Padding : <code>16px 24px</code><br/>
  Disposition : groupe d'actions aligné à droite
</div>

```tsx
{/* Pied fixe */}
<div style={{ position: "sticky", bottom: 0, background: "#ffffff",
              borderTop: "1px solid #f0f0f0", padding: "16px 24px" }}>
  <div style={{ display: "flex", alignItems: "center", gap: 12, justifyContent: "flex-end" }}>
    {/* 3e action optionnelle */}
    <Link variant="secondary" hideArrow onClick={onSaveDraft}>
      Enregistrer comme brouillon
    </Link>
    <PrimaryButton outline label="Précédent" onClick={onPrev} />
    <PrimaryButton label="Suivant" onClick={onNext} />
  </div>
</div>
```

<div className="g h2">7. Colonne contextuelle (droite)</div>

<div className="spec">
  Flex : <code>1</code> — occupe le reste de la largeur<br/>
  Border left : <code>1px solid #e5e7eb</code><br/>
  Overflow : <code>hidden</code> — la carte ou la visualisation gère son propre rendu<br/>
  Pas de padding — le contenu (carte, image) occupe 100% de la zone
</div>

<div className="g h2">8. Volet latéral contextuel (bibliothèque, fichiers…)</div>

Un panneau secondaire peut s'ouvrir en glissant depuis la droite par-dessus la colonne contextuelle.

<div className="spec">
  <div className="label">Dimensions</div>
  Largeur : <code>900px</code><br/>
  Hauteur : <code>100%</code><br/>
  Border-radius : <code>10px 0 0 10px</code> (arrondi côté gauche uniquement)

  <br/><br/>
  <div className="label">Transition d'ouverture</div>
  Propriété : <code>transform: translateX()</code><br/>
  Timing : <code>300ms cubic-bezier(0.4, 0, 0.2, 1)</code><br/>
  Fermé : <code>translateX(100%)</code> → Ouvert : <code>translateX(0)</code>

  <br/><br/>
  <div className="label">Ombre</div>
  <code>box-shadow: -4px 0 24px rgba(0, 0, 0, 0.12)</code>
</div>

```css
.side-panel {
  position: absolute;
  top: 0;
  right: 0;
  width: 900px;
  height: 100%;
  background: #ffffff;
  border-radius: 10px 0 0 10px;
  box-shadow: -4px 0 24px rgba(0, 0, 0, 0.12);
  transform: translateX(100%);
  transition: transform 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

.side-panel--open {
  transform: translateX(0);
}
```

<div className="g h2">Règles</div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Chaque section est séparée par <code>border-bottom: 1px solid #f0f0f0</code> — jamais par un espace vide seul.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Les actions de navigation sont toujours en position sticky en bas du panel.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Utiliser <code>SegmentedControlAlt</code> (jamais <code>SegmentedControl</code>) dans les sections de formulaire.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas faire scroller la page entière — seul le panel gauche est scrollable.</span></div>
