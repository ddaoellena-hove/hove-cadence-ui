# Boutons

<div className="g h2">Trois niveaux d'action</div>

<table>
  <thead>
    <tr><th>Niveau</th><th>Composant</th><th>Quand l'utiliser</th><th>Exemple</th></tr>
  </thead>
  <tbody>
    <tr>
      <td>1 — principal</td>
      <td><code>PrimaryButton</code></td>
      <td>L'action principale de la vue. <strong>Un seul par vue</strong> (une modale, un popover ou un toast comptent comme une vue).</td>
      <td>« Créer », « Enregistrer », « Appliquer »</td>
    </tr>
    <tr>
      <td>2 — secondaire</td>
      <td><code>GhostButton</code></td>
      <td>Actions secondaires : sans fond ni bordure au repos, voile au survol. Plusieurs autorisés.</td>
      <td>« Annuler », « Exporter », « Réinitialiser »</td>
    </tr>
    <tr>
      <td>2 — secondaire (dashboard)</td>
      <td><code>PrimaryButton outline</code></td>
      <td>Actions secondaires d'un dashboard : contour visible, repérable sur une page chargée. Ailleurs, <code>GhostButton</code>.</td>
      <td>« Exporter », « Filtres »</td>
    </tr>
    <tr>
      <td>3 — tertiaire</td>
      <td><code>Link hideArrow</code></td>
      <td>3e action d'un groupe, ou action dans une phrase.</td>
      <td>« Enregistrer comme brouillon »</td>
    </tr>
  </tbody>
</table>

<div className="g h2">Règles</div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Un seul <code>PrimaryButton</code> plein par vue ; plusieurs <code>GhostButton</code> (ou <code>PrimaryButton outline</code> en dashboard) sont autorisés.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text"><code>GhostButton</code> par défaut ; <code>PrimaryButton outline</code> pour les actions secondaires d'un dashboard. Pas de mélange des deux dans un groupe.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Ghost à gauche, Primary à droite ; la 3e action est un <code>Link hideArrow</code>, à gauche du groupe.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Les boutons d'un même groupe ont la même <code>size</code>. En tête de dashboard, tous en <code>sm</code>, action principale comprise.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Un <code>GhostButton</code> isolé porte une icône (<code>iconStart</code>) ou se trouve à côté d'un <code>PrimaryButton</code>.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Icône seule : <code>icon</code> + <code>aria-label</code> (obligatoire).</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas utiliser <code>PrimaryButton</code> pour de la navigation — préférer <code>Link href</code>.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas mettre deux <code>PrimaryButton</code> côte à côte.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas désactiver un bouton sans expliquer pourquoi via un <code>TooltipTrigger</code>.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text"><code>SecondaryButton</code> est déprécié : le bleu plein n'est plus utilisé pour les actions.</span></div>

<table>
  <thead>

  </thead>
  <tbody>
    <tr><td><code>md</code> (défaut)</td><td>34px</td><td>12px</td><td><strong>Actions principales</strong> : en début de page (page liste, page de détail) et en fin de formulaire. Aussi : modale, empty state</td></tr>
    <tr><td><code>sm</code></td><td>29px</td><td>11px</td><td><strong>Actions plus discrètes</strong> : tout l'en-tête de dashboard, action principale comprise ; tableau, barre d'outils, barre de sélection, popover, toast, <code>FilterBar</code></td></tr>
  </tbody>
</table>

<p>Pas de grande taille : l'importance d'une action, c'est son niveau, pas sa taille.</p>

<div className="g h2">Exemples</div>

```tsx
// Fin de formulaire — les trois niveaux
<div style={{ display: "flex", alignItems: "center", gap: 12, justifyContent: "flex-end" }}>
  <Link hideArrow onClick={onSaveDraft}>Enregistrer comme brouillon</Link>
  <GhostButton label="Réinitialiser" onClick={onReset} />
  <PrimaryButton label="Créer le scénario" onClick={onSubmit} loading={isSaving} />
</div>

// Barre de sélection d'une liste
<div style={{ display: "flex", gap: 8 }}>
  <GhostButton size="sm" iconStart="copy-01" label="Dupliquer" onClick={onDuplicate} />
  <PrimaryButton size="sm" iconStart="trash" tone="danger" label="Supprimer" onClick={onDelete} />
</div>

// Action inline à côté d'un champ
<GhostButton iconStart="plus" label="Ajouter" onClick={onAdd} />
```
