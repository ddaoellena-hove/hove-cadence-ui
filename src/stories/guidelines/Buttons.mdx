# Boutons

<div className="g h2">Choisir le bon bouton</div>

<table>
  <thead>
    <tr><th>Composant</th><th>Quand l'utiliser</th><th>Exemple</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><code>PrimaryButton</code></td>
      <td>Action principale de la page. <strong>Un seul par vue.</strong></td>
      <td>« Créer », « Enregistrer », « Lancer »</td>
    </tr>
    <tr>
      <td><code>SecondaryButton</code></td>
      <td>Actions secondaires ou alternatives. Peut être utilisé plusieurs fois.</td>
      <td>« Exporter », « Annuler », « Voir les détails »</td>

      <td>« Retour », « En savoir plus », « Supprimer »</td>
    </tr>
  </tbody>

<div className="g h2">Règles</div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Un seul <code>PrimaryButton</code> par zone d'action — il représente l'intention principale.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Placer le bouton principal à droite quand il est aligné avec un bouton secondaire.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Utiliser le variant <code>danger</code> de <code>Link</code> pour les actions destructives (suppression).</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas utiliser <code>PrimaryButton</code> pour des actions de navigation — préférer <code>Link</code>.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas empiler deux <code>PrimaryButton</code> côte à côte.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas désactiver un bouton sans expliquer pourquoi via un <code>Tooltip</code>.</span></div>

<div className="g h2">Hiérarchie visuelle recommandée</div>

```tsx
// ✅ Bonne structure dans un formulaire
<div style={{ display: "flex", gap: 8, justifyContent: "flex-end" }}>
  <SecondaryButton label="Annuler" onClick={onCancel} />
  <PrimaryButton label="Enregistrer" onClick={onSave} />
</div>

// ✅ Action destructive
<Link variant="danger" onClick={onDelete}>Supprimer le scénario</Link>
```
