# Feedback & messages

<div className="g h2">AlertToast</div>

```tsx
// ✅ Usage — afficher en overlay, coin supérieur droit
<AlertToast
  variant="success"
  title="Scénario créé"
  description="Le scénario a été enregistré avec succès."
  onClose={() => setVisible(false)}
/>

// ✅ Durée recommandée : auto-dismiss après 4s pour success/info,
//    persistant (onClose manuel) pour error/warning
```

<div className="g h2">Tooltip</div>

```tsx
// ✅ Informer sur un élément sans surcharger l'interface
<TooltipTrigger tooltip={<Tooltip label="Exporter en CSV" arrowPosition="bottom" />}>
  <SecondaryButton label="Exporter" />
</TooltipTrigger>

// ✅ Expliquer un bouton désactivé
<TooltipTrigger tooltip={<Tooltip label="Sélectionne un réseau d'abord" arrowPosition="bottom" />}>
  <PrimaryButton label="Analyser" disabled />
</TooltipTrigger>
```

<div className="g h2">Règles</div>
