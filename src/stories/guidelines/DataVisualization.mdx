<div className="g h2">Règles d'application</div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Toujours assigner les couleurs dans l'ordre (1 → 8) — ne pas sauter une couleur ni les mélanger aléatoirement.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Utiliser <code>#F04E4E</code> exclusivement pour les états d'erreur ou incidents critiques — ne pas l'utiliser comme couleur de série normale.</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Utiliser <code>#55606E</code> pour tout élément neutre ou non catégorisé (ex : « Autres »).</span></div>
<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Limiter à 5 séries maximum sur un même graphique — au-delà, regrouper dans « Autres » (<code>#55606E</code>).</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas utiliser ces couleurs pour le texte courant ou les éléments d'interface — elles sont réservées aux données.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne pas modifier la teinte ou la luminosité d'une couleur pour créer des variantes — utiliser l'opacité (<code>0.3</code>) pour les zones de fond.</span></div>
<div className="rule dont"><span className="rule-icon">✗</span><span className="rule-text">Ne jamais juxtaposer <code>#6B3FD6</code> et <code>#5A2D82</code> dans le même graphique sans légende claire — trop proches visuellement.</span></div>

<div className="rule do"><span className="rule-icon">✓</span><span className="rule-text">Intensités (heatmap) : rampe <code>--cadence-dataviz-seq-1..7</code>, une teinte pétrole à clarté croissante, lisible en daltonisme.</span></div>

<div className="g h2">Tokens CSS</div>

Les couleurs vivent dans <code>tokens.css</code> sous <code>--cadence-dataviz-*</code>. Les anciens noms <code>--CAI-dv-series-1..8</code> restent valides (alias).

```css
:root {
  --cadence-dataviz-series-1: #6b3fd6;  /* Violet       — 6,35:1 */
  --cadence-dataviz-series-2: #1a91e8;  /* Bleu         — 3,35:1 */
  --cadence-dataviz-series-3: #007d79;  /* Teal         — 4,99:1 */
  --cadence-dataviz-series-4: #b36b00;  /* Ambre        — 4,18:1 (ex-#f1a21b) */
  --cadence-dataviz-series-5: #a0185e;  /* Magenta      — 7,53:1 */
  --cadence-dataviz-series-6: #f04e4e;  /* Corail       — 3,56:1 */
  --cadence-dataviz-series-7: #5a2d82;  /* Violet foncé — 9,85:1 */
  --cadence-dataviz-series-8: #55606e;  /* Ardoise      — 6,39:1 */

  --cadence-dataviz-seq-1: #eaf4f5;     /* … rampe séquentielle … */
  --cadence-dataviz-seq-7: #004650;

  --cadence-dataviz-threshold: #1a3e45;
  --cadence-dataviz-threshold-breach: #b91c1c;
  --cadence-dataviz-annotation: #55606e;
}
```
