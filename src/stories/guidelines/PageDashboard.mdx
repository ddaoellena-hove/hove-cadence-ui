# Page de type Dashboard

Référence : **ScenariosMobilite**

<div className="g h2">1. Structure globale</div>

La page est composée de trois zones empilées verticalement dans un conteneur pleine hauteur :

```
┌─────────────────────────────────────────────────┐
│  Header de page (breadcrumb + titre + actions)  │
├─────────────────────────────────────────────────┤
│  Carte principale (onglets + tableau + vide)    │
└─────────────────────────────────────────────────┘
```

```tsx
<AppLayout sidebar={<Sidebar … />}>
  <div style={{ display: "flex", flexDirection: "column", gap: 24 }}>
    <PageHeader breadcrumbs={…} title="Scénarios de mobilité" actions={…} /> {/* collé en haut au défilement */}
    <ContentCard />  {/* onglets + actions + tableau */}
  </div>
</AppLayout>
```

<div className="g h2">2. Header de page</div>

Le header est un <code>PageHeader</code> : fil d'Ariane et titre à gauche, actions à droite, sur une seule ligne. Il reste collé en haut de l'écran au défilement.

<div className="spec">
  <div className="label">Composant</div>
  <code>PageHeader</code> — <code>breadcrumbs</code> (<code>Breadcrumbs</code>), <code>title</code> (h1, display 22px), <code>subtitle</code> facultatif, <code>actions</code><br/>
  Sticky en haut du conteneur d'<code>AppLayout</code> ; liseré bas quand le contenu défile dessous

  <br/><br/>
  <div className="label">Actions (droite)</div>
  Tout en <code>sm</code> ; sélecteurs (période, liste) en <code>variant="button"</code> ; bascule de vue : <code>SegmentedControl</code>
</div>

```tsx
<PageHeader
  breadcrumbs={
    <Breadcrumbs items={[
      { id: "home", label: "Accueil", href: "#" },
      { id: "current", label: "Scénarios de mobilité" },
    ]} />
  }
  title="Scénarios de mobilité"
  actions={
    <SegmentedControl
      options={[{ value: "list", label: "Liste" }, { value: "map", label: "Carte" }]}
      value={view}
      onChange={setView}
    />
  }
/>
```

<div className="g h2">3. Carte principale</div>

Toute la zone de contenu est encapsulée dans une carte blanche.

<div className="spec">
  <code>background: #ffffff</code><br/>
  <code>border-radius: 12px</code><br/>
  <code>box-shadow: 0 1px 4px rgba(0, 0, 0, 0.07)</code><br/>
  <code>overflow: hidden</code> — pour que les onglets touchent les bords
</div>

<div className="g h2">4. Rangée d'onglets et actions</div>

La rangée supérieure de la carte est divisée en deux zones : les onglets à gauche, les actions à droite. Elle a une `border-bottom` qui la sépare du tableau.

<div className="spec">
  <div className="label">Onglets</div>
  Composant : <code>Tab</code>, gap <code>16px</code>, texte en <strong>UPPERCASE</strong><br/>
  Padding de la rangée : <code>0 24px</code><br/>
  Border bottom : <code>1px solid #f0f0f0</code>

  <br/><br/>
  <div className="label">Actions (droite)</div>
  <code>Toggle</code> + <code>PrimaryButton</code> — séparés par <code>gap: 16px</code><br/>
  Alignés verticalement au centre de la rangée<br/>
  Le <code>PrimaryButton</code> est toujours l'action de création principale, en <code>size="sm"</code> comme tous les boutons de l'en-tête de dashboard
</div>

```tsx
<div style={{ display: "flex", alignItems: "center", justifyContent: "space-between",
              padding: "0 24px", borderBottom: "1px solid #f0f0f0", height: 52 }}>
  <div style={{ display: "flex", gap: 16 }}>
    <Tab label="En cours" variant="active" />
    <Tab label="À venir" />
    <Tab label="Passées" />
    <Tab label="Brouillon" />
  </div>
  <div style={{ display: "flex", alignItems: "center", gap: 16 }}>
    <div style={{ display: "flex", alignItems: "center", gap: 8 }}>
      <Toggle state={mapView ? "active" : "default"} onChange={setMapView} />
      <span>Affichage cartographique</span>
    </div>
    <PrimaryButton size="sm" label="Créer un scénario de mobilité" onClick={onCreate} />
  </div>
</div>
```
