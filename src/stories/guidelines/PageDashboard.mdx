# Page de type Dashboard

Référence : **ScenariosMobilite**

<div className="g h2">1. Structure globale</div>

La page est composée de trois zones empilées verticalement dans un conteneur pleine hauteur :

```
┌─────────────────────────────────────────────────┐
│  Header de page (breadcrumb + titre + actions)  │
├─────────────────────────────────────────────────┤
│  Carte principale (onglets + tableau + vide)    │
└─────────────────────────────────────────────────┘
```

```tsx
<div style={{ display: "flex", flexDirection: "column", height: "100%", padding: "24px 32px", gap: 24 }}>
  <PageHeader /> {/* breadcrumb + titre + SegmentedControl */}
  <ContentCard />  {/* onglets + actions + tableau */}
</div>
```

<div className="g h2">2. Header de page</div>

Le header regroupe sur une seule ligne : le breadcrumb + NavigationDropdown à gauche, et un `SegmentedControl` de bascule de vue à droite.

<div className="spec">
  <div className="label">Breadcrumb</div>
  Composant : <code>Breadcrumbs</code> + <code>NavigationDropdown</code> en position centrale<br/>
  Police : Inter 12px / 400 — couleur parents <code>#888</code>, courant <code>#555</code><br/>
  Séparateur : <code>#ccc</code>

  <br/><br/>
  <div className="label">Titre de page</div>
  Police : Uxum Grotesque, 28px, weight 500, couleur <code>#002830</code><br/>
  Margin top : <code>6px</code> sous le breadcrumb

  <br/><br/>
  <div className="label">Bascule de vue (droite)</div>
  Composant : <code>SegmentedControl</code><br/>
  Aligné verticalement avec le titre, <code>align-self: flex-end</code>
</div>

```tsx
<div style={{ display: "flex", alignItems: "flex-end", justifyContent: "space-between" }}>
  <div>
    <Breadcrumbs items={[
      { id: "home", label: "Accueil", href: "#" },
      { id: "current", label: "Scénarios de mobilité" },
    ]} />
    <h1 style={{ fontFamily: "Uxum Grotesque", fontSize: 28, fontWeight: 500,
                 color: "#002830", margin: "6px 0 0" }}>
      Scénarios de mobilité
    </h1>
  </div>
  <SegmentedControl
    options={[{ id: "list", label: "Liste" }, { id: "map", label: "Carte" }]}
    value={view}
    onChange={setView}
  />
</div>
```

<div className="g h2">3. Carte principale</div>

Toute la zone de contenu est encapsulée dans une carte blanche.

<div className="spec">
  <code>background: #ffffff</code><br/>
  <code>border-radius: 12px</code><br/>
  <code>box-shadow: 0 1px 4px rgba(0, 0, 0, 0.07)</code><br/>
  <code>overflow: hidden</code> — pour que les onglets touchent les bords
</div>

<div className="g h2">4. Rangée d'onglets et actions</div>

La rangée supérieure de la carte est divisée en deux zones : les onglets à gauche, les actions à droite. Elle a une `border-bottom` qui la sépare du tableau.

<div className="spec">
  <div className="label">Onglets</div>
  Composant : <code>Tab</code>, gap <code>16px</code>, texte en <strong>UPPERCASE</strong><br/>
  Padding de la rangée : <code>0 24px</code><br/>
  Border bottom : <code>1px solid #f0f0f0</code>

  <br/><br/>
  <div className="label">Actions (droite)</div>
  <code>Toggle</code> + <code>PrimaryButton</code> — séparés par <code>gap: 16px</code><br/>
  Alignés verticalement au centre de la rangée<br/>
  Le <code>PrimaryButton</code> est toujours l'action de création principale
</div>

```tsx
<div style={{ display: "flex", alignItems: "center", justifyContent: "space-between",
              padding: "0 24px", borderBottom: "1px solid #f0f0f0", height: 52 }}>
  <div style={{ display: "flex", gap: 16 }}>
    <Tab label="En cours" active />
    <Tab label="À venir" />
    <Tab label="Passées" />
    <Tab label="Brouillon" />
  </div>
  <div style={{ display: "flex", alignItems: "center", gap: 16 }}>
    <Toggle label="Affichage cartographique" checked={mapView} onChange={setMapView} />
    <PrimaryButton label="Créer un scénario de mobilité" onClick={onCreate} />
  </div>
</div>
```
